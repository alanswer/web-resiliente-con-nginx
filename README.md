# Web Resilient Platform with WordPress

Proyecto académico desarrollado para la asignatura Administración de Servidores.

## Descripción

Se implementó una plataforma WordPress de alta disponibilidad utilizando múltiples máquinas virtuales para garantizar la continuidad del servicio ante fallos.

## Tecnologías utilizadas

- Ubuntu Server
- WordPress
- HAProxy
- Nginx
- MariaDB
- NFS
- VirtualBox

## Características

- Balanceo de carga con HAProxy
- Dos servidores WordPress redundantes
- Almacenamiento compartido mediante NFS
- Replicación de base de datos MariaDB
- Pruebas de tolerancia a fallos
